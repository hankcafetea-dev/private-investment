# 台股盤中警示 → LINE（個人使用）

交易照樣在國泰樹精靈下單；這支程式用永豐金 API 只拿「行情」，照你的自選股清單盯盤，把警示推播到你的 LINE。

## 會收到什麼

| 類型 | 何時送 | 例子 |
| --- | --- | --- |
| 關鍵警示（立即） | 停損、停利、到買進提醒價、突破、漲停、跌停 | 🔴 停損 2330 台積電 913（-7.7%）跌破停損價 920 |
| 一般警示（每 15 分鐘合併一則） | 漲跌幅達 3%／5%／7%、預估爆量、自選股重大訊息 | 📈 大漲 2454 聯發科 漲幅達 5% |
| 新聞摘要 | 09:05、12:00 | 自選股新聞標題與連結 |
| 收盤摘要 | 13:35 | 每檔收盤、漲跌、量比、持股未實現損益 |

每檔股票的每種警示一天只提醒一次。一般警示與新聞每天最多 12 則（可在 settings.json 改），關鍵警示與收盤摘要不受此限。

## 第 1 步：永豐金證券 API（只拿行情）

1. 線上開立永豐金證券戶（不需要在那邊交易）。
2. 登入永豐金證券網站，申請 API Key 與 Secret Key。權限只要「行情」，不要開「交易」。
3. 依官方教學完成首次登入測試：https://sinotrade.github.io/tutor/login/
4. 記下 API Key 與 Secret Key。

## 第 2 步：LINE 官方帳號（推播用）

LINE Notify 已在 2025 年 3 月底停止服務，現在要用官方帳號加 Messaging API：

1. 到 LINE Official Account Manager 建立一個官方帳號（名稱隨意，例如「我的盯盤」）。
2. 在官方帳號設定中啟用 Messaging API，然後到 LINE Developers 後台：
   - Messaging API 分頁 → 發行 **Channel access token（long-lived）**
   - Basic settings 分頁 → 最下方的 **Your user ID**（U 開頭）
3. 用手機 LINE 加這個官方帳號為好友。
4. 免費方案每月推播則數有限，請在官方帳號的「方案」頁確認額度，再調整 settings.json 的 `max_messages_per_day`。

## 第 3 步：安裝

1. 安裝 Python 3.10 以上（Windows 安裝時勾選 Add to PATH）。
2. 解壓縮本資料夾，在資料夾內開啟終端機，執行：

   ```
   pip install -r requirements.txt
   ```

3. 把 `.env.example` 複製一份改名為 `.env`，填入第 1、2 步拿到的四個值。**.env 不要給任何人看、不要上傳。**
4. 用 Excel 編輯 `watchlist.csv`（存檔時選「CSV UTF-8」）：

   | 欄位 | 說明 |
   | --- | --- |
   | 代號、名稱 | 必填代號；名稱用於新聞搜尋 |
   | 持有股數、成本 | 有持股才填，用於停損判斷與收盤損益 |
   | 買進提醒價 | 跌到這個價格以下提醒 |
   | 突破提醒價 | 漲到這個價格以上提醒 |
   | 停損價 | 有持股且跌破時提醒 |
   | 停利價 | 漲到時提醒 |

   **在國泰買賣後，記得更新持有股數與成本。**

## 第 4 步：測試

```
python intraday.py --demo        # 假資料模擬一整天，訊息印在螢幕上
python intraday.py --test-line   # 手機應收到「LINE 連線測試成功」
python intraday.py --dry-run     # 盤中執行：真實行情，訊息只印在螢幕上
```

三個都正常後，正式執行：

```
python intraday.py
```

開盤前啟動，13:35 送出收盤摘要後自動結束。執行期間電腦不能睡眠或關機。

## 第 5 步：每天自動啟動

- **Windows**：工作排程器 → 建立基本工作 → 每週一到五 08:45 → 啟動程式選 `run_windows.bat`。電源選項設定「插電時不睡眠」。
- **Mac**：系統設定 → 能源 → 防止自動睡眠；終端機執行 `crontab -e`，加入一行：
  `45 8 * * 1-5 /bin/bash /你的路徑/tw_line_alert/run_mac.sh`

## 目前的限制

- 重大訊息使用證交所開放資料，只含上市公司，更新時間可能比公開資訊觀測站晚；上櫃股票的重大訊息尚未接入。
- 新聞來自 Google 新聞搜尋，可能有不相關或重複的標題。
- 行情來自永豐 API；永豐對每日流量有上限，自選股維持在 50 檔以內即可。
- 本程式只做提醒，不會下單，也不構成投資建議。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| intraday.py | 主程式 |
| watchlist.csv | 自選股與提醒價（你維護） |
| settings.json | 檢查頻率、警示級距、每日上限等設定 |
| .env | 金鑰（你建立，不可外流） |
| logs/ | 每天的所有警示紀錄，包含超過上限沒送出的 |
| state/ | 當天已提醒過的項目，避免重複 |
